# 🧠 QUIZZI – General Knowledge Quiz Application

QUIZZI is a modern and interactive General Knowledge Quiz Application developed using React and Vite. The application allows users to test their knowledge through multiple-choice questions from various categories such as science, history, geography, sports, technology, and current affairs.

The project is designed with a responsive and attractive user interface featuring animated components, glowing effects, and smooth transitions to provide an engaging quiz experience.

# 🎮 How to Use the Application

1. Open the application in your browser.
2. Click on the **Start Quiz** button.
3. Read each question carefully.
4. Select the correct option.
5. Correct answers turn green.
6. Wrong selected answers turn red.
7. Navigate using NEXT and PREV buttons.
8. Final score appears after quiz completion.
9. Click **Retake Quiz** to restart the quiz.

---

# 🧩 Quiz Rules

- Each question has only one correct answer.
- Users can select only one option per question.
- Once selected, the answer cannot be changed.
- Score is calculated based on correct answers.
- Final result is displayed at the end.
